# Eternal Vault

**Eternal Vault** is an offline Path of Exile 2 unique item tracker designed for collectors and completionists. Keep track of your unique item collection with a dark, immersive interface inspired by ancient vaults and arcane reliquaries.

## Features

- **Offline-First**: All data stored locally with optional Google Drive JSON sync
- **Complete Item Database**: Track all uniques in game with detailed information
- **Advanced Filtering**: Filter by ownership status, league availability, and chance orb compatibility
- **Category Organization**: Browse items by type (amulets, rings, body armours, weapons, etc.)
- **Search Functionality**: Quickly find specific items in your collection
- **Foil Tracking**: Mark special foil versions of items
- **League Tracking**: Record which league you obtained items in
- **Dark Vault Aesthetic**: Immersive UI inspired by PoE's atmosphere

## Design Philosophy

Eternal Vault embraces a **dark relic vault aesthetic** - mysterious, reverent, and powerful. The interface features:

- Deep blacks and stone greys evoking ancient crypts
- Ancient gold accents for prestige highlights
- Arcane ember orange for interactive elements
- Eldritch green for completion and ownership markers
- Subtle animations and glows, never flashy or neon

The app is designed to feel like managing a sacred archive of powerful relics, not just a checklist.

## Technical Details

- Built with Electron, React, and TypeScript
- Cross-platform: macOS and Windows
- No internet connection required
- Lightweight and fast
- Regular updates with new items as PoE2 expands

## Use Cases

Perfect for players who want to:

- Complete their unique item collection
- Track progress toward collecting all uniques
- Identify missing items for target farming
- Organize their vault by categories
- Remember which items they've chanced or obtained during specific leagues
